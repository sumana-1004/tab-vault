# 🗂️ Tab Vault

**Never lose an accidentally closed tab again.**  
A lightweight, privacy-first cross-browser extension (Manifest V3) that automatically vaults closed tabs with open-duration tracking, instant search, permanent pinning, and one-click JSON backup.

## ✨ Features
- **Automatic Vaulting:** Captures closed tabs automatically in the background without slowing down your browser.
- **Duration Tracking:** Shows how long each tab stayed open before closing so you can spot forgotten research tabs.
- **Pin Forever (`★`):** Keep critical tabs pinned at the top even when clearing your vault.
- **Instant Search & Filter:** Filter by All or Pinned tabs and search across titles and URLs in real time.
- **100% Local & Private:** Zero external servers or tracking—everything lives in `browser.storage.local` with one-click JSON export.

## 🧭 Installation (Safari on macOS — No Xcode Needed)
1. Go to the [**Actions** tab](https://github.com/sumana-1004/tab-vault/actions) of this repository and click the latest **Build Safari macOS Extension** run.
2. Under **Artifacts**, download **`Tab-Vault-macOS-Safari`**.
3. Unzip it and move **`Tab Vault.app`** into your **Applications** folder (Right-click $\rightarrow$ **Open** the first time).
4. Open **Safari** $\rightarrow$ **Settings** $\rightarrow$ **Advanced** $\rightarrow$ check **Show features for web developers**, then under the **Develop** menu check **Allow Unsigned Extensions**.
5. Go to **Safari** $\rightarrow$ **Settings** $\rightarrow$ **Extensions** and enable **Tab Vault**.
